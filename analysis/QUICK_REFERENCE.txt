🚨 SageMaker 问题根源
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ❌ 不支持 embedding 任务类型
  ❌ 只能使用 feature-extraction (返回原始输出)
  ❌ 缺少 mean pooling 处理
  ❌ 缺少 L2 归一化
  ❌ 即使手动归一化,相似度仍然只有 25%

💡 推荐方案
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  🥇 vLLM (最佳性能)
     • 兼容 OpenAI API
     • 性能最优
     • 生产就绪
     
     from openai import OpenAI
     client = OpenAI(base_url="http://localhost:8000/v1")
     response = client.embeddings.create(...)

  🥈 Ollama (最简单)
     • 一键部署
     • 零配置
     • 适合开发
     
     ollama pull BIaoo/lca-qwen3-embedding
     ollama embed BIaoo/lca-qwen3-embedding "text"

  🥉 AWS Bedrock (企业级)
     • 托管服务
     • 自动扩展
     • 成本较高

  ⚠️ SageMaker (不推荐)
     • 需要自定义 inference.py
     • 部署复杂度极高
     • 见 SAGEMAKER_ANALYSIS.md
